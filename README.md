# Лендинг «Разработка лендинга»

Статика без сборки. Дизайн-система — в `DESIGN.md`, лицензии стоковых фото — в `assets/img/stock/LICENSES.txt`.

- Ссылки в меню и подвале идут от корня (`/policy`, `/#contact`) — сайт должен открываться в корне домена или поддомена.
- `404.html` на Apache подключает `.htaccess`, на nginx — `error_page 404 /404.html;`.
- `_redirects` и `.nojekyll` нужны только для Netlify и GitHub Pages, на хостинг их не загружать.
- Форма заявки в блоке «Контакты» закомментирована, заявки принимает квиз Marquiz.
- Квиз Marquiz — `6ad8c4495385bf000f80d24b` (код в `<head>` и ссылки кнопок `#popup:marquiz_…` на всех страницах), чат Jivo — виджет `g4qOkSOokL`.
- `assets/img/og-image.png` — превью для соцсетей, снимок первого экрана 1727×911; при смене заголовка первого экрана его нужно переснять.
